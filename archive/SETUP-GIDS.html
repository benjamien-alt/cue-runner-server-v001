🎭 CUE RUNNER — Online viewers instellen

Stap-voor-stap: van nul naar live viewers via internet. Geen technische kennis vereist.

Wat je gaat bereiken: Andere mensen kunnen via een weblink live meekijken met jouw CUE RUNNER — ze zien de klok, actieve cue, volgende cue en de cuelijst. Ze kunnen niets bedienen.
Wat je nodig hebt
📋

Voorbereiding — 3 bestanden

Je hebt deze 3 bestanden nodig (staan allemaal in de zip die je hebt gedownload):

  • server.js — de relay server
  • package.json — zegt Render wat het moet installeren
  • cue-runner-viewer.html — de viewer pagina

Bewaar ze samen in één map op je computer, bijv. cue-runner-server

Deel 1 — GitHub account aanmaken (5 min, eenmalig)
1

Maak een gratis GitHub account aan

GitHub is een gratis opslagplaats voor code. Render leest je code van daaruit.

  • Ga naar github.com
  • Klik Sign up
  • Kies een gebruikersnaam, e-mail en wachtwoord
  • Bevestig je e-mail
2

Maak een nieuwe repository aan

Een "repository" is gewoon een map op GitHub.

  • Klik rechtsboven op het + icoontje → New repository
  • Naam: cue-runner-server
  • Zet op Public
  • Vink aan: Add a README file
  • Klik Create repository
3

Upload je 3 bestanden naar GitHub

Je bent nu op de pagina van je nieuwe repository.

  • Klik op Add file → Upload files
  • Sleep de 3 bestanden (server.js, package.json, cue-runner-viewer.html) in het vak
  • Scroll naar beneden → klik Commit changes
✅ Je ziet nu de 3 bestanden in je GitHub repository
Deel 2 — Server deployen op Render (5 min)
4

Maak een gratis Render account aan

  • Ga naar render.com
  • Klik Get Started for Free
  • Kies Sign up with GitHub (makkelijkst — koppelt automatisch)
  • Geef Render toestemming tot je GitHub account
5

Maak een nieuwe Web Service aan

  • Klik in het Render dashboard op New + → Web Service
  • Kies Build and deploy from a Git repository
  • Klik Next
  • Zoek je repository cue-runner-server op → klik Connect
6

Configureer de service

Vul deze gegevens in (de rest laat je staan):

  • Name: cue-runner-server
  • Region: Frankfurt (EU Central) — voor lage latency in België
  • Branch: main
  • Runtime: Node
  • Build Command: npm install
  • Start Command: node server.js
  • Instance Type: Free

Klik onderaan op Create Web Service

7

Wacht op de deploy (~2 minuten)

Render installeert nu alles automatisch. Je ziet logs stromen. Wacht tot je bovenaan Live ziet staan (groen bolletje).

✅ Je server URL verschijnt bovenaan, bijv.:
https://cue-runner-server.onrender.com

Dit is jouw permanente server URL. Noteer hem!

Deel 3 — Verbinden en viewers uitnodigen
8

Broadcast starten vanuit Cue Runner

Open je cue-runner-desktop.html in Chrome/Edge.

  • Klik op ● Uit rechtsboven
  • Vul in: wss://cue-runner-server.onrender.com
  • ⚠️ Let op: gebruik wss:// (met extra s), niet ws://
  • Klik Verbinden
✅ Status wordt groen: ● LIVE
9

Viewers uitnodigen

Stuur deze link naar iedereen die mee wil kijken (backstage, techniek, regie, ...):

https://cue-runner-server.onrender.com/viewer?server=wss://cue-runner-server.onrender.com

Vervang cue-runner-server door jouw eigen naam als je die anders hebt ingesteld.

  • Werkt op telefoon, tablet, laptop
  • Werkt in elke browser (Chrome, Safari, Firefox)
  • Geen app installeren
  • Alleen-lezen — niemand kan iets bedienen
⚠️ Gratis tier — belangrijk voor voorstellingen
De gratis server slaapt na 15 minuten zonder gebruik.

Oplossing: open de viewer URL minimaal 5 minuten voor de show. De server wordt dan wakker (duurt ~60 seconden) en blijft actief zolang er viewers verbonden zijn of de Cue Runner data stuurt.

Problemen?
❓

Server werkt niet / viewers zien niets

  • Check of Render de service op Live staat (groen bolletje in dashboard)
  • Controleer dat je wss:// gebruikt (met s) en niet ws://
  • Open https://jouw-naam.onrender.com/health — je moet JSON zien
  • De server was mogelijk in slaap — wacht 60 seconden en probeer opnieuw
